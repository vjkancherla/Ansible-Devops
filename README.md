# Ansible-Devops

Hands-on **Ansible** learning modules that progress from first playbooks to
advanced inventory, parallelism, modules, and playbook patterns.

## What's inside

Organised into numbered topics, each with an `ansible.cfg`, inventory
(`hosts.ini` / `pods-hosts.ini`) and a `Notes.txt` explaining the concept:

- `0005-Inventory` — inventory files and host definitions
- `0010-First-PlayBook` — your first playbook
- `0015-AnsibleCfg-Advanced-Inventory` — ansible.cfg and advanced inventory
- `0017-Parallelism` — parallel task execution
- `0019-Using-Modules-Adhocly` — ad-hoc module usage
- `0021-Targetting-Specific-Servers` — targeting specific hosts
- `0023-Common-Modules-Usecases` — common module use cases
- `0030-Playbook-Apache` — a playbook that deploys Apache with static files

Plus setup notes (`0000-_Install-Ansible`, `0000-_Sources`) and a Docker image
example (`0000-DockerImage`).

## Tools covered

- Ansible playbooks, modules, and ad-hoc commands
- Inventory management and host targeting
- Configuration via ansible.cfg

## How to use

Open each numbered folder and read its `Notes.txt` to learn the concept, then
inspect the accompanying playbook and inventory files.
